# لیدیاب ترب

شماره فروشگاه‌های حضوری تهران را از ترب پیدا می‌کند و به‌صورت اکسل تحویل می‌دهد.

## نصب روی سرور (Docker)
```bash
docker compose up -d --build
```
پنل: `http://SERVER-IP:8080`

همه داده‌ها (لیدها، تاریخچه، لاگ، تنظیمات) در دیتابیس Postgres (Neon) ذخیره می‌شوند — آدرسش در `src/db.js` هاردکد است. پوشه `data/` فقط پروفایل مرورگر را نگه می‌دارد.

## استفاده
1. **تنظیمات ← پروکسی‌ها:** لیست پروکسی‌ها را پیست کنید و «تست» بزنید.
2. **تنظیمات ← دسته‌ها:** دسته‌های مورد نظر را تیک بزنید و ذخیره کنید.
3. **خانه:** «به‌روزرسانی لیدها» را بزنید. (یا در تنظیمات، ساعت به‌روزرسانی خودکار روزانه را بگذارید.)
4. **دانلود لیدهای جدید:** فقط فروشگاه‌هایی که قبلاً دانلود نکرده‌اید.

- اگر برنامه وسط کار قطع شود، دفعه بعد دقیقاً از همان‌جا ادامه می‌دهد.
- دفعه‌های بعد فقط محصولات و فروشگاه‌های **جدید** را می‌گیرد (لیست ترب را از جدیدترین می‌خواند و به محصولات قبلی که رسید، می‌ایستد).
- «تاریخچه اجراها» در صفحه خانه: هر اجرا با آمار، دسته‌ها و لاگ کامل.

## اجرای لوکال (توسعه)
```bash
npm install
npm run dev        # API روی 3001 + پنل روی http://localhost:5173
HEADLESS=0 npm run dev   # با پنجره مرورگر
```
Chromium را از نصب Playwright (`~/.cache/ms-playwright`) پیدا می‌کند؛ اگر نیست: `npx playwright install chromium`.
